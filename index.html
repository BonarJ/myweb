Flashcard Belajar Web & GitHub

Klik kartu untuk membalik jawaban 3D, saring materi sesuai topik, dan tandai kartu yang sudah Anda kuasai—semuanya berjalan murni dengan HTML5 & CSS3 tanpa JavaScript.

Uji Pemahaman Cepat (Tanpa JS)

Pilih salah satu jawaban di bawah untuk langsung memeriksa hasilnya dan melihat skor otomatis.

🎯 Skor Kuis: / 4 Benar
1. Selektor CSS mana yang memungkinkan kita mengubah gaya halaman berdasarkan checkbox yang dicentang di dalamnya?
Penjelasan: Pseudo-class :has() berfungsi sebagai parent selector sehingga elemen induk seperti body dapat merespons status :checked pada elemen anak.
2. Agar sisi belakang kartu 3D tidak terlihat menembus sisi depan saat belum dibalik, properti apa yang digunakan?
Penjelasan: backface-visibility: hidden menyembunyikan bagian punggung elemen saat diputar 180 derajat pada sumbu Y atau X.
3. Tag apa yang ditulis di dalam <head> pada index.html untuk memanggil file style.css?
Penjelasan: Tag <link rel="stylesheet" href="style.css"> menghubungkan dokumen HTML dengan file stylesheet eksternal di folder yang sama.
4. Bagaimana cara membuat tombol "Reset" yang mengosongkan semua pilihan input tanpa JavaScript?
Penjelasan: Elemen <button type="reset"> di dalam <form> merupakan fitur bawaan HTML untuk mengembalikan seluruh checkbox dan radio button ke kondisi awal.

Cara Mengunggah 2 File Terpisah (index.html & style.css) ke GitHub

Kode Anda sudah saya pisahkan menjadi 2 file di dalam paket ZIP. Pastikan kedua file diletakkan sejajar di dalam folder utama (root) repositori GitHub Anda:

📁 nama-repositori-github/ ├── 📄 index.html ← Berisi struktur HTML & <link rel="stylesheet" href="style.css"> └── 🎨 style.css ← Berisi seluruh kode desain, animasi 3D, dan Dark Mode
1

Ekstrak File ZIP

Unduh file flashcard-github-pages.zip dari lampiran chat, lalu ekstrak sehingga Anda mendapatkan 2 file: index.html dan style.css.

2

Unggah Kedua File Sekaligus

Di repositori GitHub Anda, klik Add file → Upload files, tarik kedua file (index.html dan style.css) bersamaan, lalu klik Commit changes.

3

Aktifkan GitHub Pages

Buka tab Settings → Pages, pilih branch main dan klik Save. Halaman index.html otomatis memanggil style.css!
